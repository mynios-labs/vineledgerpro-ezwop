Shipping flow controls

After buying a label, do not auto mark as Shipped by default. Set status to Label purchased. Show two buttons: Print label and Confirm shipped. When the user clicks Confirm shipped, post tracking to eBay and flip to Shipped.

Add a project setting to allow auto mark as Shipped immediately after label purchase. Default is off.

Buyer change and exception handling

On each Unshipped order card, add Edit before purchase. Allow changing service selection, signature required, insurance amount, and ship from preset.

Add Address override with a warning and audit log. If Shippo flags risk, show an address correction modal.

Add Void label within the carrier void window. If voided, refund and revert status to Unshipped.

Add Reprint label that returns the existing PDF without a second charge.

If a buyer requests expedited shipping after purchase, allow Upgrade service before Confirm shipped. Charge adjustment is manual for now and tracked in a note field.

Orders list is always fetched from eBay first. Local rows are only caches for speed.

If eBay shows an order as shipped outside the app, detect drift and update local status and timeline on the next sync.
