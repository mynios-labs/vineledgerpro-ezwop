You are getting a 400 from eBay because the Inventory API is rejecting your Accept-Language header. eBay Sell APIs want BCP-47 values like en-US, and the header is optional. The fastest fix is to drop the header entirely for Sell calls, keep only X-EBAY-C-MARKETPLACE-ID: EBAY_US, and retry. You also need to guarantee source: "ebay" on every row you upsert so the UI never hits undefined again.

Sample mapping to adapt to your Drizzle schema:

const priceCents = l.price != null ? Math.round(l.price * 100) : null;
await db
  .insert(inventoryItems)
  .values({
    ebayItemId: l.itemId ?? null,
    sku: l.sku ?? null,
    title: l.title ?? null,
    priceCents,
    source: "ebay",
    state: l.status, // "live" | "ended" | "draft"
    vineItemId: null,
  })
  .onConflictDoUpdate({
    target: [inventoryItems.ebayItemId], // if null, switch to sku target
    set: {
      title: l.title ?? null,
      priceCents,
      state: l.status,
      source: "ebay",
    },
  });


Important: if ebayItemId is null but sku exists, use a second upsert path keyed on sku.
